# Theme: Modern Light Corporate

Tema claro corporativo moderno de alta visibilidad para entornos industriales o de alta iluminación.

---

## 🎨 Tokens de Color

| Token Name | Código Hexadecimal | Uso en la Aplicación |
| :--- | :--- | :--- |
| **`background`** | `#F8FAFC` | Fondo claro slate ultra limpio |
| **`cardBg`** | `#FFFFFF` | Tarjetas y cuadros en blanco puro |
| **`cardBorder`** | `#E2E8F0` | Bordes gris claro sofisticados |
| **`emerald`** | `#059669` | Acento verde menta corporativo (Listo) |
| **`cobalt`** | `#2563EB` | Acento azul corporativo (En Proceso) |
| **`amber`** | `#D97706` | Acento ámbar industrial (Completado) |
| **`red`** | `#DC2626` | Alertas rojo intenso |
| **`textMain`** | `#0F172A` | Texto principal gris oscuro de alto contraste |
| **`textMuted`** | `#64748B` | Texto secundario gris slate |

---

## ⚙️ Configuración en `.env`

```env
THEME=emerald_light
```
