# Theme: Nordic Frost

Tema elegante de inspiración escandinava con tonos azul hielo, marina profundo y verde agua de alto contraste.

---

## 🎨 Tokens de Color

| Token Name | Código Hexadecimal | Uso en la Aplicación |
| :--- | :--- | :--- |
| **`background`** | `#0F172A` | Fondo azul noche nórdico |
| **`cardBg`** | `#1E293B` | Superficie de paneles azul slate |
| **`cardBorder`** | `#334155` | Divisores y bordes finos |
| **`emerald`** | `#38BDF8` | Acento azul cielo glacial (Listo) |
| **`cobalt`** | `#14B8A6` | Acento verde turquesa (En Proceso) |
| **`amber`** | `#F59E0B` | Acento ámbar nórdico (Completado) |
| **`red`** | `#F43F5E` | Alertas rojo carmesí |
| **`textMain`** | `#F8FAFC` | Texto en blanco nieve |
| **`textMuted`** | `#94A3B8` | Texto azul plomo suave |

---

## ⚙️ Configuración en `.env`

```env
THEME=nordic_frost
```
