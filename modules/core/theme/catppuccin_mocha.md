# Theme: Catppuccin Mocha

Tema ultra popular basado en la galardonada paleta suave **Catppuccin Mocha**, optimizado para el máximo confort visual en jornadas extensas de trabajo.

---

## 🎨 Tokens de Color

| Token Name | Código Hexadecimal | Uso en la Aplicación |
| :--- | :--- | :--- |
| **`background`** | `#1E1E2E` | Fondo Base Catppuccin Mocha |
| **`cardBg`** | `#181825` | Superficie Mantle / Crust de tarjetas |
| **`cardBorder`** | `#313244` | Bordes Surface0 pastel |
| **`emerald`** | `#A6E3A1` | Acento Verde Catppuccin suave (Listo) |
| **`cobalt`** | `#89B4FA` | Acento Azul Catppuccin (En Proceso) |
| **`amber`** | `#F9E2AF` | Acento Amarillo Catppuccin (Completado) |
| **`red`** | `#F38BA8` | Alertas Rojo Catppuccin pastel |
| **`textMain`** | `#CDD6F4` | Texto principal Catppuccin Text |
| **`textMuted`** | `#A6ADC8` | Texto secundario Catppuccin Subtext |

---

## ⚙️ Configuración en `.env`

```env
THEME=catppuccin_mocha
```
