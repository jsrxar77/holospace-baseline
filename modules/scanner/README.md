# Módulo Scanner Móvil (Expo / React Native) — HoloSpace Baseline

Aplicación móvil operativa para operarios de depósito.

## Capacidades:
- Escaneo de códigos de barra EAN-13 vía cámara del celular.
- Conexión instantánea mediante código QR emitido por la Web.
- Sincronización offline/online con SQLite local (`holospace.db`).
- Validación en vivo contra el pedido asignado.
