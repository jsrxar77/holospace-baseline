# Módulo Tenant (Gobierno SaaS) — HoloSpace Baseline

Panel exclusivo para el rol **SUPERADMIN** encargado del aprovisionamiento de organizaciones (Tenants), gestión de suscripciones y asignación de licencias modulares en tiempo real.

## Capacidades:
- Directorio de Organizaciones (Alta, Edición, Suspensión).
- Catálogo de Planes SaaS (Starter, Pro, Enterprise).
- Asignación de cuotas (usuarios máximos y órdenes/mes).
- Licenciamiento Modular en caliente (`core`, `tenant`, `kanban`, `scanner`).
- Auditoría global de plataforma.
