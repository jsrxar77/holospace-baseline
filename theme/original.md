# Theme: Original Dark Glassmorphism (Default)

Este es el tema oficial y predeterminado de **PhoneWare**. Ofrece un diseño cibernético oscuro premium (*dark glassmorphism*) con acentos verde esmeralda, azul cobalto y amarillo ámbar de alto contraste.

---

## 🎨 Tokens de Color (Design System)

| Token Name | Código Hexadecimal | Uso en la Aplicación |
| :--- | :--- | :--- |
| **`background`** | `#0B0E14` | Fondo principal de la pantalla y la aplicación |
| **`cardBg`** | `#161B22` | Superficie de tarjetas Kanban, modales y tablas |
| **`cardBorder`** | `#30363D` | Bordes sutiles y divisores |
| **`emerald`** | `#00E676` | Acento principal de marca, estado LISTO, aciertos |
| **`cobalt`** | `#3B82F6` | Estado EN PROCESO, enlaces e indicadores secundarios |
| **`amber`** | `#F59E0B` | Estado COMPLETADO, avisos de advertencia |
| **`red`** | `#FF5252` | Alertas de error, desvinculación y acciones destructivas |
| **`textMain`** | `#FFFFFF` | Texto principal de títulos e indicadores |
| **`textMuted`** | `#8B949E` | Texto secundario, subtítulos y etiquetas |

---

## ⚙️ Configuración en `.env`

```env
THEME=original
```
