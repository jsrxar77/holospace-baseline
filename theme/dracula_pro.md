# Theme: Dracula Pro

Tema basado en la célebre paleta Dracula Pro, optimizado para máxima legibilidad y descanso visual.

---

## 🎨 Tokens de Color

| Token Name | Código Hexadecimal | Uso en la Aplicación |
| :--- | :--- | :--- |
| **`background`** | `#282A36` | Fondo carbón Dracula |
| **`cardBg`** | `#44475A` | Superficie de tarjetas e inputs |
| **`cardBorder`** | `#6272A4` | Bordes en azul pastel |
| **`emerald`** | `#50FA7B` | Acento verde menta neón (Listo) |
| **`cobalt`** | `#BD93F9` | Acento morado lavanda (En Proceso) |
| **`amber`** | `#FFB86C` | Acento naranja pastel (Completado) |
| **`red`** | `#FF5555` | Alertas rojo intenso |
| **`textMain`** | `#F8F8F2` | Texto en blanco suave |
| **`textMuted`** | `#8BE9FD` | Texto cian pastel secundario |

---

## ⚙️ Configuración en `.env`

```env
THEME=dracula_pro
```
