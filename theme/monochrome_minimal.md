# Theme: Monochrome Minimal

Tema minimalista industrial de alto contraste en blanco y negro puro con detalles sutiles en plata.

---

## 🎨 Tokens de Color

| Token Name | Código Hexadecimal | Uso en la Aplicación |
| :--- | :--- | :--- |
| **`background`** | `#000000` | Fondo negro absoluto 100% |
| **`cardBg`** | `#111111` | Superficie de paneles negro carbón |
| **`cardBorder`** | `#222222` | Bordes finos de alto contraste |
| **`emerald`** | `#FFFFFF` | Acento blanco puro monocromático (Listo) |
| **`cobalt`** | `#CCCCCC` | Acento plata brillante (En Proceso) |
| **`amber`** | `#888888` | Acento gris medio (Completado) |
| **`red`** | `#FF4444` | Alertas rojo puro |
| **`textMain`** | `#FFFFFF` | Texto blanco nitidez extrema |
| **`textMuted`** | `#777777` | Texto secundario plomizo |

---

## ⚙️ Configuración en `.env`

```env
THEME=monochrome_minimal
```
