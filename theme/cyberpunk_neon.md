# Theme: Cyberpunk Neon

Tema de estilo futurista de alto impacto visual con tonos cian eléctrico, magenta neón y fondo violeta nocturno.

---

## 🎨 Tokens de Color

| Token Name | Código Hexadecimal | Uso en la Aplicación |
| :--- | :--- | :--- |
| **`background`** | `#0A0A12` | Fondo violeta noche profundo |
| **`cardBg`** | `#121224` | Tarjetas y contenedores con brillo neón |
| **`cardBorder`** | `#2D2B55` | Bordes en púrpura eléctrico |
| **`emerald`** | `#00F0FF` | Acento cian eléctrico vibrante (Listo) |
| **`cobalt`** | `#A855F7` | Acento púrpura neón (En Proceso) |
| **`amber`** | `#FF007F` | Acento magenta neón (Completado) |
| **`red`** | `#FF3366` | Alertas rojo fluorescente |
| **`textMain`** | `#FFFFFF` | Texto en blanco brillante |
| **`textMuted`** | `#A594F9` | Texto lavanda claro |

---

## ⚙️ Configuración en `.env`

```env
THEME=cyberpunk_neon
```
